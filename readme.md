# Project Paleo-Maiden
A game project about dinosaur girls duking it out to be the best fighter. Currently in the concepting phase as we figure out the identity of the game. If you'd like to learn more about the world, do refer to https://dodowingster.github.io/Project-Paleo-Maiden/ (may not be up to date as of writing, but I'll get to it someday)
This project is currently being built in Godot 4.6, though this may change further down the line.

Also the repo is in quite a mess right now, will be cleaned up when time permits oop

The gameplay loop is currently planned to take place in a board game setting, with occasional auto-battles occuring as players move through the map. Therefore, there are 2 main concept scenes that are currently being worked on to test ideas.

# Godot Project Files
If you'd like to try running the game, the folder to open in Godot is auto-battler-prototype.

To try out the WIP auto-battler concept, run BattleSetup.tscn, found under UI > Menus > Battle.

To try out the WIP board game section, you can run MainMenu.tscn, found under UI > Menus > Main_Menu
